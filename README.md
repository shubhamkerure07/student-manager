## 📌 Overview

A clean, responsive native Android application designed to streamline student administrative workflows. Easily store, organize, edit, and query student profiles, course enrollments, and academic performance data.

---

## ✨ Features

- 👤 **Student Profiles**: Add and manage comprehensive student records (USN, Name, Semester, Department).
- 🔍 **Instant Search**: Query students quickly by name or roll number.
- 📊 **Academic Performance**: Track internal marks, attendance statistics, and grade histories.
- 🎨 **Modern Material UI**: Clean Android Material 3 design principles.

---

## 🛠️ Tech Stack

- **Language**: Kotlin
- **Platform**: Android SDK
- **Architecture**: MVVM (Model-View-ViewModel)
